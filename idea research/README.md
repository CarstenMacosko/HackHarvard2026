# Idea research

Research gathered while choosing our HackHarvard 2026 project.

## Main research

- [Longitudinal study drift agent](longitudinal-study-drift-agent.md): the leading idea for the Regeneron "Reinvent Clinical Trials" track. A version-aware monitoring agent that knows which protocol version, lab method, coding dictionary and site roster applied to every data point, and works out what an amendment or measurement change breaks. Covers which Regeneron starter sheets it answers, where it is most useful, the architecture, judge objections and a 36-hour build plan.
